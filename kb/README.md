# Knowledge Base Template

This folder contains a generic example structure for an AI support agent knowledge base.

The structure provided here is only a recommended template.
You can fully replace it with your own documentation model, folder naming, sections, business logic, product terminology and support workflows.

The agent does not require your knowledge base to follow this exact structure.
It only needs access to readable documentation files that can be indexed and used as grounding context for support answers.

## Purpose

Use this folder to store the documentation that the AI support agent should rely on when answering user questions.

## Important

Do not store secrets or private credentials in this folder.

## Suggested template structure

The folders included in this repository are examples only.
You can keep this structure, modify it, remove sections or replace it entirely.
