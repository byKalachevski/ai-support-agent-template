## Recommendations

- Keep semantic structure clear.
- Group related topics logically.
- Use one topic per file when possible.
- Prefer Markdown (`.md`) for structured documentation.
- Avoid storing secrets, tokens or sensitive data.
- Maintain consistent naming and hierarchy.
